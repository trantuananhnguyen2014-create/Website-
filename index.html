GitHub Pages 404 Fix

v1.0
404 — File not found
The site configured at this address does not contain the requested file.
1 Kiểm tra file index.html
GitHub Pages yêu cầu file index.html ở thư mục gốc (root) của branch được cấu hình.
# Cấu trúc thư mục hợp lệ: my-repo/ ├── index.html ← BẮT BUỘC ├── style.css └── script.js
2 Kiểm tra branch & thư mục nguồn
Vào Settings → Pages kiểm tra:
  • Branch: main hoặc gh-pages
  • Folder: / (root) hoặc /docs
# Nếu dùng /docs, cấu trúc phải là: my-repo/ └── docs/ └── index.html ← file trong docs/
3 Kiểm tra tên file (phân biệt chữ hoa/thường)
GitHub Pages phân biệt chữ hoa chữ thường.
Index.html ≠ index.html
Đảm bảo URL trỏ đúng tên file (ví dụ: /About.html).
4 Cấp quyền & deploy lại
Sau khi push code, đợi 1-2 phút để GitHub build.
Vào Actions kiểm tra workflow có thành công không.
# Force redeploy: git commit --allow-empty -m "trigger rebuild" git push origin main

📋 Kiểm tra nhanh

  • ✅ Đã có index.html ở thư mục gốc hoặc /docs
  • ✅ Branch đúng (main / gh-pages) và folder được chọn
  • ✅ Tên file viết thường (index.html)
  • ✅ Đã commit & push lên remote
  • ✅ Đợi ít nhất 2 phút sau khi push
  • ⚠️ Nếu dùng custom domain, kiểm tra file CNAME
